# Phase 7 Internationalization and SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish independently addressable, server-rendered Portuguese and English portfolio pages with context-preserving language navigation and coherent per-page search metadata.

**Architecture:** Follow ADR-0002: existing unprefixed routes remain Portuguese, English lives under `/en/`, and a pure route registry owns localized path segments and fragments. Thin locale route entries share Astro page composition and typed bilingual content. Browser JavaScript may enhance section preservation but never owns page language, content, routes, or metadata.

**Tech Stack:** Astro 7 static output, TypeScript content/route data, browser ES modules, `@astrojs/sitemap`, Node test runner, real-browser audit.

**Spec:** `D:/dev/Projetos/portifólioV2 temporario/Handoff-Bloco-B.md` (Phase 7 objectives at lines 289–312) and `docs/adr/ADR-0002-localized-static-routes-and-seo-identity.md`

## Global constraints

- PT and EN preserve meaning, facts, evidence, maturity, and positioning; each language must read naturally rather than as a forced literal translation.
- Preserve the Phase 5 hierarchy and every Phase 6 accessibility, responsive, focus, form, and reduced-motion behavior.
- Portuguese keeps the current public URLs; English uses `/en/` and `/en/projects/{slug}/`.
- Language switching must be a real link and preserve the equivalent homepage section or case study when possible.
- Page language, content, metadata, canonical identity, alternates, and structured data must be rendered statically without client-side language detection.
- All canonical and alternate URLs are absolute HTTPS URLs, include the GitHub Pages base path, and use trailing slashes.
- Each page is self-canonical; reciprocal hreflang uses `pt-BR` and `en`; `x-default` points to the Portuguese equivalent.
- JSON-LD includes only claims visible on the page.
- The generated sitemap contains every canonical route. Do not claim that a repository-scoped robots file controls the GitHub Pages host root.
- Use English Conventional Commit messages. Do not push, publish, deploy, or merge `main`.

## Review focus

- Base-path duplication or omission in links and metadata must be caught (`/portifolio-miguelzg/` appears exactly once).
- Switching language from a scrolled homepage section or a case study must reach the real equivalent, not merely a language homepage.
- A localized page must never render mixed-language title, description, headings, ARIA labels, resume link, or validation feedback.
- Every hreflang set must be absolute, self-inclusive, reciprocal, and identical across its translated pair.
- Browser preference/localStorage must not silently override an explicitly requested URL language.
